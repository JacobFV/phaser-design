The optical state is never reset; masks fixed for the episode; linear readout trained by behaviour cloning and evaluated closed loop.

Storage and memory conflict

Self-imaging maximises how long a state lives but makes every past input land on the same pixels with the same phase — a readout cannot tell delays apart. Temporal memory needs distinct mode phases.

Recurrence is a low-pass filter

Between frames the static cavity applies M^K. Past the mode lifetimes (~10–100 trips here) that collapses every frame onto a few modes; at 10⁴ trips per frame the controller outputs a constant. The self-imaging ring never beats the memoryless readout.

Nonlinearity trades memory for expressivity

Adding gain saturation or Kerr solves 3-bit parity perfectly but cuts memory capacity from 35 to 5–11. Near lasing, memory vanishes.
